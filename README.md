# Full Stack Engineering Journey

A collection of my **Full Stack Engineering learning journey**, covering the technologies, concepts, notes, experiments, and projects I work through along the way.

The goal is to understand not only individual technologies, but also how they fit together to build **scalable, production-ready applications**.

## Topics

* **Languages:** JavaScript, TypeScript
* **Frontend:** React, Shopify Polaris Web Components
* **Backend:** Node.js, Express.js
* **Database:** SQL, PostgreSQL, Prisma, Redis
* **Shopify:** Admin API, GraphQL, App Bridge, Admin UI, Extensions, Metafields, Webhooks
* **Networking:** HTTP, APIs, Networking Basics
* **Architecture:** System Design, Software Architecture, Scalability, Caching
* **DevOps:** Docker, Linux, Nginx, CI/CD, GitHub Actions, Monitoring
* **Cloud:** AWS
* **Version Control:** Git, GitHub

## Structure

Topics are organized into separate folders containing:

* Notes & explanations
* Code examples
* SQL queries
* Experiments
* Mini projects
* Practical implementations
